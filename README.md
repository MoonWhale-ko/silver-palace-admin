# 실버 스트림 관리자 편집기

실제 사이트 화면(site.html)을 표시하고, 편집할 때 도구를 여는 정적 사이트입니다. 인증·서버 저장·GitHub 토큰·배포 버튼은 없습니다. 두 GitHub 저장소는 비공개로 유지합니다.

## 사용 방법

- 오른쪽 아래 편집 또는 Alt+E: 편집 모드 전환
- 기존 글자를 클릭해 오른쪽 패널에서 수정. 두 번 클릭하면 직접 입력 가능
- 글자·사각형·원·이미지 추가. 이미지 드롭·붙여넣기 지원
- 추가 요소 드래그 이동, 오른쪽 아래 모서리 드래그로 크기 조절. 수치 입력 및 방향키(Shift로 10px) 지원
- 글자색·배경색·크기·글꼴·정렬·테두리·모서리 설정
- 추가 요소 복제·삭제·앞뒤 순서·가운데 배치·잠금. 잠긴 요소는 레이어 목록에서 선택해 해제
- 실행 취소 / 다시 실행: Ctrl+Z / Ctrl+Shift+Z
- PC·모바일·태블릿 화면 너비 확인. 추가 요소 위치·크기는 화면 유형별로 수정 가능
- 브라우저 자동 임시 저장. 공간 부족 시 ZIP으로 보관
- 파일 받기 / Alt+S: 편집 데이터와 이미지 원본을 ZIP으로 받기. 자동 다운로드가 없으면 생성되는 ZIP 다운로드 링크 사용
- 파일 열기: 이 편집기에서 받은 ZIP 복원
- 처음 화면: 원본으로 되돌림. 실행 취소 가능

이미지는 PNG/JPG/WebP/GIF 8MB 이하, ZIP은 30MB 이하입니다. ZIP은 무압축 STORE 형식입니다.

## 범위와 제한

기존 글자·요소 스타일 수정과 새 글자·도형·이미지 배치를 지원하는 첫 버전입니다. 기존 레이아웃 블록 전체 이동, 다중 선택·그룹화, 자동 맞춤선, 이미지 자르기는 아직 없습니다. 추가 요소는 절대 위치 방식이므로 모바일·태블릿 배치를 따로 확인하세요.

임시 저장은 해당 브라우저에만 남습니다. ZIP으로 보관해야 다른 기기에서 이어갈 수 있습니다. 원본 화면이 바뀌면 기존 요소 ID가 달라질 수 있어 이전 파일은 검토 후 변환합니다.

## 승인 흐름

편집 → ZIP 다운로드 → 채팅에 업로드 → 코드·내용 정리 → 관리자 화면에서 확인 → 사용자 승인 → 실제 사이트 반영. 편집 파일 저장은 배포를 실행하지 않습니다.

## 구성과 검증

index.html: 편집기 틀 / site.html: 실제 사이트 화면 / editor/: 편집 UI·ZIP 처리 / assets/, data/: 렌더러·콘텐츠 / test/: ZIP 검증.

npm run check, npm test, npm run build로 검증합니다. 결과는 dist입니다. 승인 전 Cloudflare Pages 빌드는 CF_PAGES 검사로 중지됩니다. 작업은 restructure/site-admin-split 브랜치에 보관합니다.

구문·빌드·ZIP 테스트 3건 통과. 브라우저에서 편집 모드, 기존 제목·새 글자 수정, 도형 추가, 실행 취소·다시 실행, 새로고침 복원, 모바일 너비 전환, ZIP 불러오기를 확인했습니다. 검증 브라우저의 다운로드 이벤트는 시간 초과되어 다운로드 완료는 미확인입니다. 자동 다운로드와 별도 다운로드 링크를 제공합니다.
