# 실버 스트림 — 관리자 사이트

비공개 저장소. 실제 사이트와 같은 화면에 브라우저 편집 기능을 추가하는 용도입니다.

## 현재 구현

`silver-palace-guide`의 기존 화면·렌더러·콘텐츠를 동일하게 복사했습니다. 독립적으로 `npm run check`, `npm run build`를 실행할 수 있습니다. 로그인, GitHub 토큰, 서버 저장 API 및 자동 배포 기능은 없습니다. 아직 편집 도구와 파일 내보내기는 구현하지 않았습니다.

## 다음 구현

- 단축키 또는 버튼으로 편집 모드 전환
- 기존 글자 직접 수정, 글자·도형·이미지 추가
- 드래그 이동, 크기 조절, 색상·글꼴·테두리 설정
- 정렬, 복제, 그룹화, 잠금, 레이어 순서
- 실행 취소·다시 실행, 브라우저 임시 저장
- PC·모바일 미리보기
- 단축키 또는 버튼으로 이미지와 편집 데이터를 ZIP으로 내보내기

## 작업 흐름

관리자 브라우저에서 편집 → 파일 다운로드 → 채팅에 업로드 → 정리된 결과를 관리자에 반영 → 사용자 확인·승인 → 실제 사이트 반영.

인증 없이 운영하며 주소를 아는 사람은 접근 가능합니다. 편집 데이터는 방문자 각자의 브라우저에 보관하는 방식으로 구현하고 GitHub·배포 권한과 비밀값은 제공하지 않습니다.

## 화면 동기화

화면 원본은 `index.html`, `assets/`, `data/`입니다. 관리자 전용 편집 코드는 후속 작업에서 `editor/`로 분리합니다. 승인된 화면 원본을 실제 사이트로 반영하며 관리자 전용 코드는 포함하지 않습니다. 파일 반영 시 세 파일 영역을 함께 비교해 동기화합니다.

## 배포

현재 `restructure/site-admin-split` 브랜치에서 준비합니다. Cloudflare 연결·배포는 수행하지 않았습니다. 빌드 결과는 `dist/`입니다.

공개 승인 전 Cloudflare Pages 빌드는 `CF_PAGES` 검사로 중지합니다. 승인 후 배포 설정과 함께 이 임시 제한을 해제합니다.
